# GridSight 系統架構設計規範 (v5.8.5)

GridSight 是專為 70 台具備還原卡之 Windows 電腦教室打造的螢幕監控與實時廣播系統。系統兼顧「實體座位自由排版」、「全班畫面低負載輪詢」、「單機 30 FPS 焦點調閱」與「教師畫面全體廣播」四大核心需求。

---

## 2. 模組命名與職責劃分

### 教師端管理介面 (GridSight Console)
- **運行環境**：Windows (獨立單檔/免安裝綠色包) / Linux (Docker) / Web (React 18 + Vite + TailwindCSS + Node.js)
- **核心職責**：
  1. **可視化拖曳座位畫布**：支援自由網格、走道標記、講台/立柱障礙物、磁吸對齊、全景縮圖導航。
  2. **全班輪詢與即時流量統計 (Traffic HUD)**：結合 1 FPS 縮圖輪詢與全螢幕廣播 RTP 多播流量即時計算呈現。
  3. **WebCodecs GPU 硬體解碼檢視器**：接收選中學生的 30 FPS H.264 串流，超低延遲 (<50ms)。
  4. **H.264 組播廣播推送**：將教師畫面透過 UDP Multicast RTP (239.255.42.100:9000) 推送至局域網，附帶原生 True Alpha 滑鼠特效與真實游標。
  5. **課堂管理控制**：支援網址/檔案分發（含失敗重試）與遠端關機/撤銷關機 (`SHUTDOWN` / `CANCEL_SHUTDOWN`)。

### 學生端輕量代理 (GridSight Beacon / `gs-agent.exe`)
- **運行環境**：Windows 10/11 x64 (透過 MinGW-w64 靜態編譯)
- **核心職責**：
  1. **Session 1 背景運行**：透過 PowerShell 雲端熱拉取至 `%TEMP%` 於學生登入 Session 1 執行，徹底避開 Session 0 截圖隔離。
  2. **主動上線宣告 (Beacon)**：啟動時向 `239.255.42.99:8888` 發送探索包，動態取得 RAM Token 與 Teacher IP。
  3. **出站 Snapshot 推送**：每秒主動出站 `POST /api/agent/snapshot`，學生端零入站開放埠。
  4. **按需 WebSocket H.264 串流**：當教師端焦點點選時，啟動 30 FPS 串流編碼。
  5. **D3D11 / MFT 全螢幕置頂廣播接收**：接收組播 RTP 串流並以最上層無邊框視窗覆蓋顯示。
  6. **遠端電源與指令接收**：支援遠端關機 30 秒倒數視窗與教師端/學生端一鍵撤銷關機。

## 3. 三大影像傳輸模式效能對比

| 傳輸場景 | 解析度 / 幀率 | 編碼與傳輸協定 | 全班頻寬負載與效能指標 |
| :--- | :--- | :--- | :--- |
| **全班 70 台常態監控** | 480×270 @ 1 FPS | WebP/JPEG + HTTP Pull | 約 17 Mbps (佔 1GbE 頻寬 1.7%)，教師端 CPU 解碼 < 15% |
| **單機/焦點實時監看** | 720p/1080p @ 30 FPS | H.264 (OpenH264) + WebSocket | 單機 2~4 Mbps，WebCodecs GPU 硬解延遲 < 50ms |
| **教師畫面全體廣播** | 高 1080p30 / 中 720p30 / 低 480p15 | H.264 + UDP Multicast (RTP) | 三檔品質細選（8/4/1.5 Mbps），IGMP Snooping 硬體複製零延遲 |

## 4. 教師全體廣播品質選擇 (Broadcast Quality)

教師畫面全體廣播支援三檔品質快速切換（於教師端頂部導航列「廣播畫面」按鈕旁選擇），粗估全班總頻寬如下：

| 檔位 | 解析度 | FPS | 碼率 | 適用情境 |
| :--- | :--- | :--- | :--- | :--- |
| **高** | 1080p | 30 | 8 Mbps | 示範精細操作 / 高畫質數位內容 |
| **中**（預設） | 720p | 30 | 4 Mbps | 一般課堂講解平衡畫質與頻寬 |
| **低** | 480p | 15 | 1.5 Mbps | 窄頻交換器 / 降低學生端軟體解碼負擔 |

後端 `broadcastStreamer.ts` 依所選品質覆寫 FFmpeg 的 FPS、碼率 (`-b:v`) 與解析度 (`-vf scale=-2:<height>`)，維持 `ultrafast` + `zerolatency` 低延遲編碼。
