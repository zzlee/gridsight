# 🚀 未來功能企劃與目標清單 (Future Goals & Completed Milestones)

本文檔整理 GridSight 系統之**功能推進歷程**，明確區分「已落地實作之核心里程碑」與「未來規劃推進之目標清單」，供版本演進與功能規劃對齊。

---

## ✅ 已正式落地實作之核心里程碑 (Completed Milestones)

以下功能原列於早期規劃藍圖，現已 100% 於生產環境落地並納入正式版本發布：

### 1. 📡 學生示範廣播 (Student Showcase Relay) —— 【✅ v5.8.9 完整落地】
- **實作成效**：
  - **零拷貝極速直推**：示範學生端將 30 FPS H.264 串流經反向 WebSocket 推送至教師端 Node.js，後端以 FFmpeg `-c:v copy` 直推 UDP RTP 多播（`239.255.42.100:9000`），伺服器 0% 額外 CPU 解碼負擔。
  - **防鏡像遞迴抑制**：示範學生電腦右下角顯示無干擾半透明微光提示（`💡 您的螢幕正在全班轉播展示中`），學生端 `rtp_receiver.cpp` 透過 `Utils::IsShowcaseActive()` 自動抑制全螢幕彈出，徹底消除「自己看自己」的鏡像死循環。
  - **雙入口操控**：座位卡片懸浮快捷鍵、焦點視窗 (`FocusModal`) 頂部一鍵啟動/停止，導航列紫色狀態燈提示。

### 2. 🆔 學號登錄系統 (Student ID Login System) —— 【✅ 已完整落地】
- **實作成效**：
  - 學生端啟動時跳出輕量原生 Win32 登錄對話框 (`student_login.cpp`)，學生輸入學號後經由 Beacon 宣告包即時上報。
  - 教師端畫布卡片自動綁定學號與電腦名稱，適應不同班級共用同一間電腦教室時的無痛切換。

### 3. 📁 課堂作業批次收取與自動歸檔 (Classroom Assignment Dropbox) —— 【✅ v5.8.9 完整落地】
- **實作成效**：
  - 學生端 Win32 原生置頂拖曳框（`WM_DROPFILES` 免開瀏覽器），學生直接將桌面檔案拖入即繳。
  - 伺服器端依座號與電腦名自動歸檔，重複繳交自動覆蓋最新版。
  - 零外部依賴純 Node.js 原生實作 ZIP 打包串流下載（`zipPacker.ts`），一鍵帶走全班作業。

### 4. 🔒 課堂專注深藍黑屏與鍵鼠鎖定 (Screen & Input Lockout) —— 【✅ v5.8.9 完整落地】
- **實作成效**：
  - Slate-950 置頂深藍大鎖全螢幕視窗，底層 Windows 低階鉤子（`WH_KEYBOARD_LL`）遮蔽 Win 鍵、Alt+Tab、Alt+F4 與滑鼠點擊。
  - 後端 `lockedAgents` 集合持久維護，學生拔電源重開機後 WebSocket 握手自動重發補鎖，徹底防作弊。

### 5. 🎙️ 教師螢幕錄影自選音訊裝置與多播強隔離 (Selectable Audio Recording) —— 【✅ v5.8.10 完整落地】
- **實作成效**：
  - DirectShow (Windows) / PulseAudio (Linux) 實體與虛擬音效卡自動探測（含麥克風、立體聲混音、純畫面）。
  - AAC 128kbps 影音精準混流同步 (`aresample=async=1000`) 寫入 MP4。
  - 雙軌多播強隔離：多播廣播嚴格過濾阻斷聲音（`-an` 與 `select=v`），100% 杜絕全班喇叭回音嘯叫。

## 🔮 未來規劃推進目標清單 (Future Goals)

以下功能為後續版本規劃推進之核心目標：

### 1. 📝 課堂即時快問快答與隨堂測驗 (Instant Quiz & Live Polling)
- **目標**：免開瀏覽器、0 外網依賴，10 秒內完成全班觀念驗收與統計圖表。
- **預期實作方向**：
  - 教師端一鍵發起單選題 (A/B/C/D) 或是非題 (O/X)，支援限時倒數計時（如 30 秒）。
  - 學生端 C++ 自動彈出原生置頂答題按鈕卡片，學生點擊瞬間經反向 WebSocket 回傳答案。
  - 教師端畫布卡片即時顯示學生選取的選項，頂部儀表板動態繪製柱狀分佈圖，時間到一鍵公布正確答案並標亮答對座位。

### 2. 🙋 學生無聲舉手與求助追蹤系統 (Silent Hand-Raise & Help Desk)
- **目標**：解決電腦教室螢幕高遮擋視線、後排害羞學生不敢舉手以及老師漏看巡堂盲點。
- **預期實作方向**：
  - 學生端常駐右鍵選單或桌面極簡浮動快捷鍵「🙋 舉手求助」，支援選填簡短求助說明（如「編譯報錯」）。
  - 教師端畫布該座位邊框呈現亮黃色脈衝發光動效，頂部導航列浮現「🙋 待協助 (N人)」排隊清單。
  - 老師點擊清單可一鍵將畫布鏡頭平移聚焦至該座位，或雙擊調閱 30 FPS 畫面遠端排錯。

### 3. 🛡️ 上機考試防作弊：一鍵外網切斷（保留教師監控通道）(Exam Network Shield)
- **目標**：考試時切斷一切外網搜尋與通訊通聯，但 100% 保留教師畫面監看、作業收取與黑屏管制。
- **預期實作方向**：
  - 教師端一鍵啟用「考場防作弊模式」。
  - 學生端 C++ 動態配置本機出站防火牆規則：嚴格僅放行往教師 IP（Port 3000、UDP 8888/9000）之通訊，其餘所有預設閘道 (Default Gateway)、網際網路與跨學生機 LAN 流量全數阻斷。
  - 考完一鍵解禁恢復。

### 4. ⚡ 學生端 H.264 解碼「GPU 硬解優先 + CPU 軟解無縫降級」雙層管線 (Hardware MFT D3D11VA)
- **目標**：進一步降低學生端接收 1080p 廣播時的 CPU 佔用率。
- **預期實作方向**：
  - 引進與編碼端（`encoder.cpp`）相同的 `MFTEnumEx` 雙層探測機制：優先啟用硬體加速（Intel QuickSync / NVIDIA NVDEC / AMD VCN，D3D11VA）達到 0% CPU 解碼；若機器無硬解或初始化失敗，自動無痛降級至現行 CPU SIMD 軟體解碼。

### 5. 🖱️ 廣播視窗滑鼠自動跟隨 (Auto-Tracking Mouse on Broadcast)
- **目標**：解決學生端螢幕解析度小於教師端時的局部細節觀看體驗。
- **預期實作方向**：
  - **通訊傳輸管道**：**嚴格統一採用既有之專屬 UDP 多播通道 `239.255.42.100:9002`（`TeacherInputRtpStreamer` 與 `InputRTPReceiver`）**。嚴禁使用 WebSocket 反向中繼傳輸高頻滑鼠座標，以確保 <5ms 超低延遲、0 伺服器中繼負擔，並徹底避免 TCP 隊頭阻塞 (Head-of-Line Blocking)。
  - **視窗 1:1 原生清晰渲染**：學生端視窗模式（或解析度小於教師機時）以 1:1 原生解析度裁切顯示，清晰看清程式碼文字。
  - **邊界死區與平滑阻尼**：邊界死區（Deadzone，中央 60%）觸發與平滑彈簧插值平移，設定最大平移限速，避免劇烈晃動造成暈眩。

### 6. 🖥️ 廣播視窗遠端強制全螢幕模式 (Immersive Fullscreen Broadcast)
- **目標**：教師端發起廣播時，可自選是否下發指令強制學生端全螢幕置頂覆蓋，隱藏所有 Windows 工具列。
- **預期實作方向**：
  - 在廣播啟動 payload 增加 `forceFullscreen: true` 旗標，學生端 `rtp_receiver.cpp` 解析後直接觸發全螢幕覆蓋。

### 7. 🤖 AI 離題行為輔助分析 (AI Behavioral Insights)
- **目標**：在現有使用中視窗標題監控基礎上，整合輕量特徵分析，提供課堂專注度報表。
